# Archived: protocol version 3 outputs

These files are the study outputs generated under protocol version 3 (freeze commit `7403e51`), unchanged:

- `log.jsonl`: 60 rows, claude-opus-5-5 and gpt-6-astra, 3 levels x 5 runs x 2 stages.
- `selected_scales.md`, `selected_scales.csv`: the Stage 1 draw from that pool (seed 20261028).
- `pool_report.csv`, `pool_summary.md`: the pool description.

Why archived: version 4 changed the response scale named in the prompt from "strongly disagree / strongly agree" to Edmondson's "very inaccurate / very accurate", so AI and validated items share one response format in the survey. The version 3 scales were written for a different response format, so the study uses a new pool generated under version 4. They were not replaced because of their content or results. They are kept so the full history stays visible.
